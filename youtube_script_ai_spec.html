Mô tả sản phẩm
YouTube Script AI Generator

Công cụ web hỗ trợ creator Việt Nam tạo kịch bản YouTube từ các video nguồn tiếng nước ngoài (trọng tâm: kênh lịch sử/tiền sử châu Âu). Người dùng nhập URL video → AI tự động trích xuất nội dung, phân tích cấu trúc, và sinh ra kịch bản song ngữ Anh–Việt bám sát video gốc.

Đối tượng người dùng
Creator YouTube

Muốn làm video về lịch sử/tiền sử châu Âu theo phong cách các kênh lớn nhưng bằng tiếng Việt

Biên kịch

Cần công cụ tham khảo cấu trúc kịch bản từ video nước ngoài để phóng tác hoặc Việt hóa

Mục tiêu Phase 1 (MVP)
  • Nhập YouTube URL → tự động lấy transcript
  • Gemini API phân tích transcript → tóm tắt cấu trúc video
  • Sinh kịch bản bám sát gốc bằng 2 ngôn ngữ song song (EN gốc + VI dịch)
  • Giao diện web sạch, có thể copy kịch bản
Ngoài phạm vi Phase 1
  • Kịch bản sáng tạo / Gợi ý video tiếp theo (Phase 2)
  • Đăng nhập / lưu lịch sử (Phase 3)
  • Export PDF/DOCX (Phase 3)
  • NotebookLM integration — không khả thi, dùng Gemini thay thế

Lộ trình triển khai chi tiết
Phase 1

MVP — Bản làm việc được

Thời gian: 5–7 ngày

Phase 2

Sáng tạo & Gợi ý

Thời gian: +3–5 ngày

Phase 3

Polish & Export

Thời gian: +3–4 ngày

Ngày 1 — Setup & UI cơ bản Hôm nay
• Khởi tạo React + Vite + Tailwind
• Giao diện nhập URL + Gemini API Key
• FastAPI scaffold cơ bản
• Tích hợp Gemini API đơn giản (test với text input)
Ngày 2 — Transcript pipeline
• Tích hợp youtube-transcript-api trong FastAPI
• Xử lý các trường hợp: video private, không có phụ đề
• Fallback textarea nhập thủ công
• Test với 5–10 video thật
Ngày 3 — Prompt Engineering
• Tinh chỉnh prompt phân tích cấu trúc
• Prompt sinh kịch bản EN bám sát video
• Prompt dịch + Việt hóa
• Test với video kênh tiền sử châu Âu (Toldinstone, Fall of Civilizations…)
Ngày 4–5 — Output UI + Polish Phase 1
• Giao diện hiển thị kịch bản song ngữ 2 cột
• Copy từng phần / copy toàn bộ
• Loading state, error handling
• Deploy: Vercel + Railway/Render
Ngày 6–8 — Phase 2: Sáng tạo & Gợi ý
• Kịch bản biến thể sáng tạo hơn
• 3–5 gợi ý ý tưởng video tiếp theo
• UI tab switching giữa kịch bản gốc / sáng tạo
Ngày 9–12 — Phase 3: Hoàn thiện
• Lưu lịch sử kịch bản (localStorage)
• Export .txt / .md
• Chunking xử lý video dài
• UX refinement
Phân tích rủi ro & giải pháp
Cao
YouTube chặn lấy transcript
Một số video disable phụ đề tự động, video private/age-restricted không lấy được
Giải pháp: Cung cấp textarea fallback nhập thủ công; hiển thị hướng dẫn lấy transcript từ YouTube Studio
Cao
Transcript quá dài vượt context Gemini
Video 30–60 phút có transcript 8–15k tokens, vượt giới hạn free tier
Giải pháp: Dùng Gemini 1.5 Flash (1M token context), chunking nếu cần; hiển thị warning video quá dài
Trung
Chất lượng kịch bản phụ thuộc vào prompt
Kịch bản có thể quá generic hoặc không bắt được tone video gốc
Giải pháp: Dành ngày 3 chỉ để test & tinh chỉnh prompt, có ít nhất 10 test case thật
Trung
Bản dịch tiếng Việt không tự nhiên
Gemini dịch máy có thể cứng nhắc, không phù hợp với phong cách YouTube Việt
Giải pháp: Prompt yêu cầu "Việt hóa" không chỉ dịch, thêm option chỉnh sửa thủ công trong UI
Thấp
Gemini API rate limit
Free tier: 15 requests/phút — với use case cá nhân không thành vấn đề
Giải pháp: Thêm retry logic + loading indicator; hướng dẫn upgrade nếu cần
Câu hỏi cần xác nhận trước khi code
  • Kênh cụ thể nào? — Fall of Civilizations, Toldinstone, Historigraph…? Để test prompt cho đúng tone
  • Độ dài video trung bình? — 10 phút hay 60 phút? Ảnh hưởng đến chunking strategy
  • App dùng một mình hay chia sẻ? — Nếu nhiều người dùng cần backend riêng, không để API Key phía client
  • Tên / brand của tool? — Để thiết kế UI phù hợp
