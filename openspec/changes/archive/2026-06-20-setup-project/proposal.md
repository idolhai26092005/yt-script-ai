## Why

Thiết lập cấu trúc thư mục chuẩn cho dự án YouTube Script AI (FastAPI + React Vite Tailwind) để chuẩn bị cho việc code các tính năng của Phase 1.

## What Changes

- Tạo cấu trúc thư mục backend chuẩn sử dụng FastAPI.
- Tạo cấu trúc thư mục frontend chuẩn sử dụng React + Vite + TypeScript + Tailwind CSS.
- Cài đặt cấu hình cơ bản (`requirements.txt`, `package.json`, `.env`, `vite.config.ts`).

## Capabilities

### New Capabilities
- `project-scaffolding`: Khởi tạo cấu trúc dự án và file cấu hình nền tảng.

### Modified Capabilities
None.

## Impact

Ảnh hưởng trực tiếp đến toàn bộ cấu trúc thư mục tại root của workspace.
